# Factors Influencing Student Performance: A Data-driven study of California School Districts

## Project Overview
This data science project analyzes data from 420 California school districts to understand the socio-economic and school-level factors that influence student performance in math and reading. 

## Key Questions Addressed
* How do average household income and the percentage of English learners impact test scores?
* Does expenditure per student or student-teacher ratio correlate with better academic outcomes?

## Methodology
This project was entirely coded in **R** and utilizes the following techniques:
* **Exploratory Data Analysis (EDA):** Univariate and multivariate visualizations.
* **Predictive Modeling:** Multiple Linear Regression, k-Nearest Neighbors (k-NN), and Decision Trees.
* **Unsupervised Learning:** K-means and Hierarchical Clustering to group schools based on socio-economic traits.
* **Classification:** Linear and Quadratic Discriminant Analysis (LDA & QDA) to predict "High" vs "Low" performing schools.

## Files Included
* `analysis_script.R`: The full R script used for data cleaning, EDA, and modeling.
* `DataSciProject.pdf`: The comprehensive final report with detailed interpretations and visualizations.
* `CASchools.csv`: The dataset used for this analysis.
